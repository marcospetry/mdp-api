Plataforma › Tenants › Detalhe

Tenant

Configuração do Tenant na Plataforma MDP.

Identidade do Tenant: o código é definido na criação e permanece imutável. Tenants de sistema não podem ser inativados pelo cadastro.

Configuração técnica: estes dados pertencem à Plataforma. Segredos não são retornados pela API nem exibidos nesta tela.

White-label do Backoffice: estes dados definem a identidade e o host administrativo do Tenant. Salvar o host aqui não configura DNS, certificado ou Traefik automaticamente.

Acesso ao Tenant: a identidade do usuário é central na Plataforma. Aqui administramos somente o vínculo com este Tenant. Perfil operacional e permissões por funcionalidade serão tratados nas etapas próprias, sem duplicar senha ou MFA.

Funcionalidades do Tenant: o catálogo é definido globalmente pela Plataforma. Aqui apenas habilitamos ou desabilitamos o que este Tenant pode utilizar. Uma funcionalidade inativa no catálogo global não pode ser habilitada no Tenant.

Integrações / Canais: cadastre os pontos de contato e identificação pertencentes a este Tenant. Aplicações globais, como Meta / MDP Omni, continuam em Plataforma → Provedores / Aplicações. Não armazene tokens, senhas ou App Secrets aqui.
